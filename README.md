# 🤖 Transcrição de áudio com OpenAi Whisper e Python

Projeto desenvolvido como estudo para a DIO (Digital innovation One).  
Esta aplicação utiliza o modelo **Whisper** da OpenAI para realizar transcrições de áudio em texto de forma gratuita.

## 🚀 Funcionalidades
- Transcrição de áudio para texto (Português).

- Execução em nuvem via Google Colab (utilizando GPU T4).

## 🛠️ Tecnologias
- `Python`
- `OpenAI Whisper`
- `Google Colab`

## 📖 Como usar
1. Abra o arquivo `projeto.ipynb` no Google Colab.
2. Ative a GPU em *Ambiente de Execução > Alterar tipo de ambiente*.
3. Execute as células e faça o upload do seu arquivo de áudio.
